# 종가의 제왕

주식 동아리 오프라인 레크리에이션을 위한 뉴트로 스타일의 시장 게임입니다. 국내 상장사 이름과 기본 사업 설명을 사용하지만 가격·재무·수익률은 모두 게임용 가상 데이터입니다.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 엽니다.

## 주요 화면

- `/` — 팀 참가, 관리자 게임 생성, 프로젝터 바로가기
- `/admin/lobby` — 참가 팀 확인 및 게임 시작
- `/admin/game` — 팀 현황, 시장 집중도, 자동·돌발 이슈
- `/team/game` — 팀 뉴스와 포트폴리오 현황
- `/team/portfolio` — 기업 탐색과 비중 구성
- `/display` — 16:9 프로젝터 조회 화면
- `/results` — 최종 순위와 시장 연대기

## Supabase

서울 리전의 `종가의 제왕` 프로젝트와 연결되어 있습니다. `.env.local`에는 공개 가능한 publishable key만 저장하며, 팀 원장과 숨은 시장 이벤트는 RLS로 외부 조회를 차단합니다. 공개 화면은 게임 상태·뉴스판·익명 최종 결과만 구독합니다.

`supabase/migrations`에는 재현 가능한 스키마가 있습니다. 게임 상태가 `finished`로 바뀌면 팀별 포트폴리오·대출·이자 원장을 삭제하고 팀명이 없는 최종 순위 요약만 남깁니다.
